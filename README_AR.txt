نسخة أولية لتطبيق عقارات للإيجار - موريتانيا

المحتويات:
- index.html: واجهة عربية تجريبية قابلة للعرض على الهاتف.
- manifest.json و sw.js: أساس التثبيت كتطبيق ويب تقدمي (PWA).

مهم:
- الإعلانات الحالية أمثلة تجريبية وليست بيانات حقيقية.
- لا يوجد حتى الآن تسجيل دخول أو رفع صور أو قاعدة بيانات أو رسائل.
- لنشرها مجاناً: ارفع الملفات إلى مستودع GitHub، ثم فعّل Settings > Pages > Deploy from a branch.
- بعد النشر افتح رابط GitHub Pages من Safari على iPhone، أو Chrome على Android، ثم اختر إضافة إلى الشاشة الرئيسية.
